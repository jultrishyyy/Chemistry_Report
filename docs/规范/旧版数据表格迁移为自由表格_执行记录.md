# 旧版数据表格迁移为自由表格

## 执行结果（2026-09-09）

经用户确认，在本机 `cdr_demo` 数据库执行。范围为未归档原始记录模板的当前生效版本与草稿；归档模板和历史版本不做内容替换。

- 12 个模板，14 个版本快照，共 20 处旧表格转换为 `free_grid`。
- 新版本 ID 为 96–109；其中 104、107 延续原来的已发布状态，其余保持草稿，不将原草稿自动发布。
- 原版本内容、版式及 PDF 源码保留，仅版本状态转为 superseded；当前版本指针指向相应新版本。
- 未修改历史录入数据、已生成报告、报告项目模板内容或其当前版本指针。
- 每个替换版本写入 template_audit_log；操作在单个数据库事务中完成。

## 内容和取数保护

1. 保留字段 ID、编码、名称、标题、题注及其它字段级设置。
2. 参数名、试样标签、单位/可选单位、默认值、选择项及自定义选择、汇总行/列、合并跨度转换为自由表格配置。
3. 公式转换为稳定格子引用；保留旧矩阵公式的小数位计算语义，避免迁移导致结果改变。
4. 原试样方向和试样成员保持不变；明确标为 stats 的表格不设置试样区域。不凭“平均值”“数据统计”等文字推断并改变原模板语义。
5. Excel 导入的 Sheet 等既有配置保留。
6. 通过 `legacy_matrix` 只读兼容索引和运行时取数适配保留旧报告映射。旧记录仍使用旧版本；新记录使用自由表格值，投影为旧映射所需的编码，不改写录入对象。
7. 增加试样生成独立标识；删除试样后不再从保留的旧值中取数。固定试样绑定保持原身份，不因中间删除而指向其它试样。
8. 保留原配置快照用于兼容，不代表新旧表格同时编辑。后续新增映射可以使用自由表格的稳定格子/试样区域绑定。

- 执行后再次检查落库内容、历史快照及剩余迁移项。

以上不等于逐页像素级一致：自由表格与旧矩阵的渲染器不同，默认留白、自动换行和分页仍建议在试录页面人工查看。尚未完成浏览器端真实录入→审核→生成报告的全流程验收。

## 人工验收建议

1. 重新进入模板编辑器，确认表格为自由表格；不要用迁移前仍打开的页面覆盖保存。
2. 试录透光率、密度、燃烧、弯曲模板，核对参数、单位选项、平均值公式、结论选择、题注及 PDF 换行分页。
3. 增加一个试样，填入容易辨认的数字；删除中间试样，核对剩余值未串位。
4. 使用正常项目报告验证固定格、逐试样数据、平均值与单位映射；同时确认历史记录仍能按原版本打开。
5. 测试 Sheet 导入，核对公式格不会被导入数据覆盖。

## 实现位置

- shared/migrate-matrix-to-free-grid.ts：纯转换、拒绝未验证配置、公式引用迁移。
- shared/legacy-matrix-bridge.ts：只读旧映射取数适配。
- shared/verify-matrix-migration.ts：转换前后计算比较。
- scripts/migrate-record-matrices.ts：预检、版本化事务、备份、审计及执行后核验。
- shared/migrate-matrix-to-free-grid.test.ts：迁移、动态试样、映射及精度回归测试。

脚本并非任意复杂矩阵的通用转换器：分组表头、列级表达式、跨行单值汇总列等未验证配置会中止整个事务。本次库内目标模板均通过支持范围检查。
