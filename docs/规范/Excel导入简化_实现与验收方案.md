# Excel 导入简化：实现与验收方案

日期：2026-09-09。本文覆盖本次实施；不承诺所有仪器文件均可自动识别，无法可靠判断的内容必须预览确认或手动选择。

## 1. 用户流程

模板中的自由表、矩阵仅配置“允许导入”和可选 Sheet 名称。一次录入上传一次工作簿，在一个窗口中分配各表来源。配置名称存在时自动选择；没有名称且只有一个 Sheet 时自动选择；多 Sheet 未配置、配置名称缺失时要求选择或明确跳过。临时选择不回写模板。

各表展示来源、候选区域、参数对应与写入预览。可拖拽框选工作表数据区、修正参数对应；模糊名称只提供建议。同 Sheet 的重复/重叠区域必须提示确认复用。最终一次性确认后才修改录入数据；取消、请求失败、仍有未处理表格时不得部分写入。导入完成才调用原有附件留存回调。

## 2. 现状与风险

- 原接口仅预览前6行，忽略空行会丢失坐标；原录入按固定起点直接写入，无统一预览/覆盖确认。
- 自由表受固定目标尺寸截断，不能直接用导入行数扩展试样；矩阵旧导入会自动增加参数，可能造成报告未映射。
- 配置既有0-based来源起点、目标格与旧逐列映射字段；不能删除存量字段或批量改模板。
- 原解析使用ExcelJS的xlsx读取器，不能宣称支持二进制.xls；前端原有.xls接受标记误导用户。
- 提取接口接受客户端文件路径，需限定为导入临时目录中的有效上传文件，避免任意文件访问。新流程不下发绝对路径，上传要限制尺寸，工作表要限制单元格总量并明确告知超限，不能静默截断。
- 用户可能在预览打开期间修改录入值，最终应用必须基于当前数据重新计算影响，不能覆盖过期快照。

## 3. 实现分层与文件

1. `server/src/routes/excel-import.ts`：新增受权限保护的工作簿预览接口；保留既有parse/extract路径，修复提取路径校验。按物理坐标返回完整限制范围内的表格、合并范围、解析提示；数字/文本/布尔值规范化，公式仅取已有缓存结果，不执行Excel公式或宏；无缓存、错误值明确标注不可导入。
2. `shared/excel-import.ts`：纯函数处理Sheet分配、数据区域候选、多行表头描述、名称匹配、来源重叠、目标预览和写入计划。行/列方向都保留。数字密度只用于候选定位，不能作为取值身份。
3. `client/src/components/ExcelImportWizard.tsx`：单窗口多表选择、工作表可视化框选、逐参数对应、预览、覆盖/未导入/新增试样统计与最终确认。没有证据的对应不自动确认；允许明确按位置导入。
4. `FormRenderer`：一次上传入口改用新向导；最终一次onChange并使用现有派生计算；附件回调、试录与正式录入行为保留。
5. 模板自由表/矩阵配置面板：只展示开关和可选Sheet；旧起点仅作为首次预览候选提示，用户更新配置后采用自动识别，不移除历史绑定字段。

## 4. 识别与数据保护

- 候选区域结合连续有值区、数值/检测文本、周围表头；识别结果必须展示。多表、多区域、日期/编号/限值/汇总行可能混淆，不能声称自动正确。
- 名称归一空白/换行/全半角/大小写；多行、合并表头拼接层级。精确名称可建议对应；近似名称、单位不同、重名必须核对，不自动换算单位。所有参数对应都可人工调整或跳过。
- 保留内部空行空列，不挤压数据；零值、科学计数法、带比较符值、检测文本保留。空值默认不覆盖已有值。表头、固定文字、公式、序号、合并覆盖格不写入；选项非法不写并显示统计。
- 新流程禁止自动新增参数；额外来源参数列出为未对应内容。试样增加通过已有稳定槽位API；少于现有数量不删试样、不清空尾部值。超过上限或复杂区域无法安全扩展时阻止该表导入并提供手动粘贴建议。
- 自由表读取本次实例结构；写入使用field_code、稳定行列ID及试样槽位；矩阵保留样品ID/参数code，不触碰报告绑定。导入只修改数据，不修改原模板、表头或项目模板。
- 模板之外的复杂排版、异向布局、非矩形对应不得猜测：通过人工参数对应/区域选择解决，仍不支持时明确跳过或复制粘贴。

## 5. 验收矩阵

- 无名称单Sheet、无名称多Sheet、精确命名、名称缺失、空Sheet；多表一次上传、逐表跳过、重复来源确认、关闭不写入。
- 多行表头、合并表头、空白行列、列重排、按行参数、模糊/重名/单位不一致、不含标题的数字区域、多个候选表。
- 原始表头与公式不覆盖、显式0、空值、文本检测值、选项不合法；已有值覆盖确认；同一目标仅写一次。
- 试样扩展、删除后再导入、存量块记录兼容、零试样恢复、少量数据不删尾部、超过50试样；矩阵与自由表两条路径。
- 工作簿公式缓存、日期/富文本、错误值、旧.xls明确拒绝、超大文件/表拒绝、非法临时路径拒绝。
- 单元测试以纯函数覆盖分配/识别/计划/数据不变性；实际ExcelJS构造xlsx测试解析；保留原41项表格/报告链路回归（后续新增后按实测数量记录）、前端构建与服务端类型检查。
- 人工验收：真实仪器文件上传→多表分配→拖拽→预览→覆盖确认→保存重开→PDF→报告生成；静态/单元测试不替代这项。

## 6. 实施顺序与回退

先建立纯函数与解析边界，再实现向导，最后替换配置和入口、跑回归。旧配置字段和旧接口保留，已录入数据/历史报告不迁移；新向导所有变化确认前均可取消。遇到不支持的文件或歧义不强行导入，提示转存xlsx、手动框选或Excel复制粘贴。

### 尚未完成的验收与限制

1. 尚未进行真实数据库、浏览器拖拽/弹窗点击/保存重开和真实仪器Excel端到端验收；不应跳过下节直接认为可无风险推广。
2. 自动识别是候选建议，不是通用Excel理解引擎。并排多表、数字型表头、复杂交错区域、纯文本结果可能需要手动框选。最多读取数据区前8行/列的表头上下文；参数重名、同义词和单位差异均需人工核对。
3. 参数默认自动对应，核对页可展开调整来源行或列；试样按当前显示顺序导入，不自动根据Excel试样编号重排。非准确名称匹配在核对页显示提醒；直接导入使用系统建议，不逐项询问。不支持的复杂目标可跳过并复制粘贴。
4. 模板配置不再要求坐标，但旧配置的来源起点和目标格作为兼容建议保留；更新导入配置后转为auto。未开展所有存量模板逐一验收。
5. 仅支持xlsx，不支持旧二进制xls、密码保护文件或宏工作簿；需先转存。超大文件和因整表样式产生的超大有效范围需清理/拆分。
6. 上传尺寸/解析后的维度限制不等于解压内存硬隔离；面向不可信公网文件的大规模部署还需网关速率限制、解压资源隔离及压力测试。
7. 无变化表格会提示没有可写入变化，需要明确跳过；全部跳过不能确认导入。被跳过的非空非法选项/公式目标当前显示总数，未逐项解释每个拒绝原因。

## 8. 上线前人工验收清单

使用测试模板和工单副本，至少完成以下流程：

1. 两张目标表分别配置两个Sheet名，上传一次含两Sheet的工作簿；核对两表预览→一次导入→两表值正确。
2. Sheet配置留空：单Sheet直接对应；多Sheet显示待选择。配置不存在名称时能够临时换Sheet或跳过，不改变模板。
3. 使用3行表头、带合并标题且列顺序与模板不同的Excel，核对实际导入结果；分别验证来源按行/按列的参数调整。重复对应必须拦截。核对页不再要求逐表勾选。
4. 同Sheet上下/左右放两张表，分别框选；故意选择重叠区域应要求确认复用；取消窗口后数据完全不变。
5. 原记录填111/222，Excel有0、空值、<0.01、未检出和非法选项；核对覆盖计数、空值保留、非法项跳过、表头/公式不变。
6. 按行/按列两个方向各做2→3试样扩展；保存重开检查稳定取值，生成原始记录PDF和项目报告对照。少于现有试样不应自动删尾部。
7. 先删除中间试样再导入，核对剩余试样与报告不串位；再次新增不复用删除值。
8. 预览期间触发外部数据更新，确认时应要求重新核对；确认后附件仅留存一次，取消不新增附件。
9. 上传xls、空Sheet、无公式缓存、超限表格，检查明确提示；验证试录不保存正式数据，正式录入需正常保存草稿。

出现数值错位、未经确认覆盖、公式/表头被改、试样数量变化后报告错位时应暂停推广，保留文件副本和操作步骤定位；不以人工修改报告掩盖导入错误。
## 确认界面优化（2026-09-09）

### 部分选区匹配修复

原算法逐参数匹配，未匹配参数会立即按位置占用来源，导致部分选区整体错位。现先锁定全体唯一同名匹配，再进行双向唯一的模糊匹配；单位单独参与表头拆分但不参与名称相似度，“试样/样品/试件”前缀支持近似匹配。重复名称、歧义和未选中的参数不自动补位，保留原值；仅完全无表头且参数数量一致时保留顺序建议。必要时用户仍可人工指定来源。

从数据中间开始框选时会向前查找当前连续数据块的表头，遇空白分隔终止。按行和按列使用同一逻辑。回归覆盖截图 C3:E7 对应结果 `[-1, 0, 1, 2]`，即不写弯曲强度、正确写入模量/厚度/宽度，并覆盖中间起始行、转置来源布局、模糊名称、重复名称及原值保留。

- 上传解析后先显示“直接导入 / 核对导入信息”。直接导入使用自动选区和参数匹配，一次应用所有参与表格，不要求逐表确认；找不到来源、无效计划、来源重叠未确认时转入核对页，不进行部分写入。入口明确告知可能覆盖已有值。
- 核对页展示整个工作表，保留原表头、空白、行列坐标及合并关系；蓝色“可导入区域”为自动识别的候选区域，绿色“已选择区域”为当前完整选区（包括空格，不代表每格都会写入）。实际写入仍受空值、公式、选项等校验约束。只预览数据和合并关系，不复刻 Excel 字体、图表等全部版式。
- 可直接拖动重新框选或 Shift 点击另一角，无需切换框选模式或逐表勾选。顶部提供“跳过此表格 / 恢复导入此表格”，右侧问号解释跳过不修改本表已有内容。
- “确认导入 X 张表格”默认可点击，点击后校验；全部跳过、来源不完整、重复映射等仍不会写入。录入数据在预览期间变化时要求再次确认。来源复用保留独立确认以防意外重复导入。
- 参数对应调整默认折叠：每行一个试样时选择来源列，每列一个试样时选择来源行；显示实际 Excel 列字母/行号及识别的表头，允许“不导入此参数”。保留数量与异常提示，不恢复逐格覆盖明细。自动匹配仍不保证任意异构表格正确。
- 弹窗高度随视口限制，正文纵向滚动；宽表在自身容器横向滚动。列标题和行号固定，长文本保留完整悬浮内容，不因显示截取而改变导入值。
- 40 行/20 列分页仅用于显示，不裁剪实际选区；跨页合并保留原主格内容和坐标。
- `scripts/test-excel-sheet-preview.cjs` 验证高亮、导入去向、合并、跨页、长文本、零值与无写入渲染。另回归工作簿解析、导入计划及单次导入入口。
- `scripts/test-excel-import-flow.cjs` 通过组件事件/状态测试验证方式选择、直接提交、重复提交防护、核对不写入、跳过/恢复、缺少 Sheet 转核对与取消；不替代真实浏览器交互验收。
- 人工建议验证 360px/768px/桌面宽度、长文件名、20列以上和40行以上工作表；本次未运行真实浏览器端拖拽和视口截图测试。
