# 3.4 试验模块 —— 3.4.1 / 3.4.2 章节补充


## 3.4.1 原始记录模版设计

**功能描述：**
实验室主管/工程师在系统内可视化设计原始记录模版，无需线下手工排版。模版由若干"字段"按分区组织，设计完成后经审核生效，并通过受控登记（见 3.4.2）后供试验环节"测试数据管理"按测试项目勾选绑定使用。模版采用"草稿—提交—审核—生效"的版本化管理，支持母子模版同步、版本回退与归档，保证在用记录始终对应一份可追溯的受控模版版本。

### 一、字段类别（模版可设计的内容）

原始记录模版支持以下字段类别，工程师从"添加字段"中选择，并在右侧属性面板配置；左侧结构面板组织分区与排序，右侧实时预览渲染效果（PDF）。

| 字段类别 | 说明与可配置项 |
| --- | --- |
| 文本 | 一行或多行文字（如服务编号、样品描述、备注）。可配置：标签、字段编码、是否必填、默认值、单位、说明 |
| 数字 | 数值（如温度、湿度）。可配置：单位、小数位数、是否必填、默认值 |
| 日期 | 日期选择，格式 YYYY-MM-DD |
| 选择 | 单选 / 多选 / 可自定义输入；每个选项还可挂"子字段"（选项联动展开子录入项）。可配置：选项列表、是否允许自定义、默认值 |
| 图片 | 上传样品/试验图片，区分"检测前 / 检测中 / 检测后"阶段；支持多张上传；可配置图片尺寸、排布方式、表格样式 |
| 数据表格（矩阵） | 样品 × 参数 的试验数据表。支持：参数列（编码、单位、单位可选/自定义、小数位、单元格公式）、可增删样品行/参数列、汇总行（平均/最大/最小/合格判定等多种来源：字面量、文本/数值/选择录入、公式、按列聚合、引用其他字段）、汇总列（按行聚合/公式/录入）、单元格级公式、Excel 批量导入映射（指定 sheet、起始行列） |
| 测试设备 | 从设备库按管理编号 / 仪器名称查询引用；生成报告时自动展开为设备表 |
| 间隔（空白） | 纯版式空白块，用于字段/分区之间留白（封面排版常用），可调高度，不产生数据 |

> 注：另有"报告·结论汇总表 / 报告·检测结果表 / 报告·设备表 / 报告·图片表"四类字段，仅在**报告模板**设计时可插入，原始记录模版设计时不显示，不属于本节范围。

### 二、共有字段（系统自动生成，无需手工录入）

不同检测项目的原始记录模版字段不同，但存在一批共有字段由系统自动生成/带出，与需求说明书正文 3.4 表格一致：

- **受控号、颁布日期、实施日期**：来自 3.4.2 受控登记，测试项目选定模版后自动带出并印在原始记录顶部"受控行"（随版本冻结）。
- **委托单号、样品描述、测试项目、测试方法**：测试项目选定模版、进入数据录入时，自动填充委托单及能力库信息。
- **主检/日期**：原始记录数据录入完成、保存提交后自动生成录入人与时间。

### 三、模版版本与审核流（生命周期）

模版以"版本"为单位管理，状态及流转如下：

| 状态 | 含义 | 可执行操作 |
| --- | --- | --- |
| 草稿（draft） | 设计中、未提交 | 保存为草稿、提交审核；草稿带"乐观锁"，防并发互相覆盖 |
| 待审核（pending） | 已提交，待审核员审核 | 撤回（作者或审核员）→ 回到草稿 |
| 已生效（approved） | 当前在用版本 | 可被复制(fork)、绑定到记录、回退、归档申请；生效时自动把旧的已生效版本置为"已替代" |
| 已退回（rejected） | 审核不通过，冻结保留 | 不可编辑；可在其基础上新建新版本号继续修改后再次提交 |
| 已替代（superseded） | 被新版本取代的历史版本 | 只读历史，可在版本历史中查看/作为回退源 |

**操作流程：**
1. 工程师在模版设计器编辑字段，点【保存为草稿】（首次为【创建模板】）。
2. 点【提交审核】，填写改动摘要，版本进入"待审核"。
3. 审核员在版本历史中查看与"当前生效版本"的**实时字段差异（diff）**，选择"通过"或"退回"（退回需填写意见）。
4. 通过后该版本"已生效"，旧版本自动"已替代"；退回后版本"已退回"，可再次修改提交。
5. 编辑器在存在未生效草稿/被退回版本时，会自动加载该未定稿内容继续编辑，避免覆盖他人改动。

### 四、母子模版同步（一处维护，多处生效）

- **派生（fork）**：可从某个已生效模版派生"子模版"，系统记录父模版与父版本号，并建立父子字段的映射关系（field_mapping）。
- **自动同步**：父模版审核通过后，系统自动把变更同步到各子模版，为每个子模版生成一份**待审核**版本（需各自再审核后生效），同步内容包括字段的替换、删除、（可选）新增；若子模版当前有未定稿草稿/待审核/被退回版本，则跳过不覆盖。
- **同步预览**：同步支持试运行（dryRun）与选择目标子模版，并返回受影响字段清单（替换/删除/新增）。
- 子模版自行新增、不在映射内的字段不会被父模版同步触碰。

### 五、版本回退（回退）

可将模版回退到某个历史的"已生效/已替代"版本：系统以该历史版本内容创建新草稿并自动提交为"待审核"（仍需审核后生效）；不能回退到草稿/待审核/已退回版本，且存在未定稿时不允许回退。

### 六、归档与恢复

- **归档申请**：对已生效模版可发起归档（删除）申请，填写原因，进入"待归档审核"。
- **归档审核**：审核员通过后模版软删除（归档），列表默认不显示；可取消归档申请或对已归档模版执行恢复。

### 七、版本锁定与可追溯

- 试验环节录入原始记录时，记录会**锁定**所用的模版版本号（template_version_id）。
- 回放/打印历史记录时按锁定版本渲染（含其受控号、字段结构），老记录永久保留其原始受控号与结构，满足合规追溯。
- 模版的全部关键操作（创建/修改草稿/提交/撤回/审核/派生/同步/归档/恢复/改名/受控登记）均写入操作日志，可在版本历史中查阅。

## 3.4.2 原始记录模版受控登记

**功能描述：**
按质量管理要求，原始记录模版设计、审核生效后，需经**质量管理系统受控登记**，由其返回**受控号、颁布日期、实施日期**后该模版方可正式投用，受控信息印于原始记录顶部"受控行"。

> **当前实现范围**：与质量管理系统（质量中心）对接的受控登记接口（接口传入/传出字段、触发与回传时机）**待与质量中心确认后再实现**。本系统当前已实现**手动录入受控登记内容的应急备用通道**：由具备权限的人员在系统内手工填写受控号、颁布日期、实施日期并保存，效果与接口回传一致（写入同一处）。待接口就绪后，由外部系统回传写入同一字段，无需改动下游逻辑。

### 一、手动受控登记（已实现的备用通道）

**入口：** 模版编辑器顶部工具条【受控登记】按钮（模版保存后可用）。

**录入字段（手工）：**

| 字段 | 填写说明 | 示例 |
| --- | --- | --- |
| 受控号 | 受控文件编号（含版本号），手工填写 | GRGJL.WI-HX-06-471(1.7) |
| 颁布日期 | 受控文件颁布日期 | 2025/8/20 |
| 实施日期 | 受控文件实施日期 | 2025/8/20 |

**操作流程：**
1. 模版生效后，操作人在编辑器点【受控登记】，弹窗中填写/修改上述三项（已登记过则回显当前值）。
2. 点【登记】保存：系统把三项写到该模版**当前生效版本**上，随版本快照**冻结**。
3. 保存后顶部"受控行"预览立即反映；该模版后续出具的所有原始记录顶部均印此受控信息（样式对齐参考 .xls）。
4. 该操作记入模版操作日志（动作：受控登记），可在版本历史中查阅。

### 二、受控信息的下游使用

- 受控号、颁布日期、实施日期属于原始记录"共有字段"，工程师**无需手工录入**：测试项目选定模版后由系统自动带出。
- 受控信息随模版版本冻结：记录锁定的是录入时所用模版版本，历史记录永久保留当时的受控号，模版升版不影响已出记录。

### 三、待与质量中心确认事项（接口对接，暂未实现）

以下为正式接口实现前需与质量中心确认的内容，确认后据此替换/补强手动通道：

1. **触发方式**：模版审核生效后由本系统主动推送登记，还是质量中心侧发起？
2. **接口传入**：本系统需提供的模版标识与内容（如模版名/版本号/字段结构/Typst 源/PDF 等）字段清单与格式。
3. **接口传出（回传）**：质量中心返回的受控号、颁布日期、实施日期及可能的状态/受控文件链接等字段清单。
4. **回传写入**：回传结果写入与手动通道相同的位置（当前生效版本的受控字段），保持下游一致；是否需要"已受控登记"状态以约束未登记模版不可投用。
5. **异常与重登记**：模版升版后是否需重新受控登记、登记失败的兜底（手动通道）流程。
