# 模板字段复制粘贴

原始记录、报告首页、报告项目模板共用字段编辑器的右键菜单：复制字段、粘贴字段。粘贴插在目标字段后；右键分区底部（包括空分区）可粘贴到末尾，不显示额外粘贴按钮。支持 Ctrl+C/V，Mac 支持 Command+C/V，针对当前字段操作；输入框、可编辑文本、表格、弹窗或已选中的文字保留原生复制粘贴，不触发字段操作。剪贴板保存在当前页面会话的内存中，可跨路由切换模板；不使用系统文本剪贴板，不跨标签页同步，刷新后清空。

只读时允许复制、不允许粘贴。仅允许同编辑器类型之间粘贴，并沿用新增字段的类型/分区兼容规则；图片字段须进入图片分区。签字分区保持锁定，结论专用角色及签字字段不可重复粘贴。跨模板粘贴需确认外部公式、图片来源、报告映射仍保留原配置，需人工核对。

副本保留字段内容、样式、默认值、表格行列/合并/数字规则/公式/试样区域/Excel 设置。字段及嵌套选择项字段生成不冲突的 ID 和 code；行列和试样区域 ID 属于表内作用域，保持原值以保留内部关系。显式引用自身或一并复制的子字段的公式同步重映射来源和别名；外部引用保留。报告 binding 属于原始记录来源，不随报告副本编码重映射。操作只修改模板编辑草稿，不写入试录/正式记录数据，不自动保存模板。

验证：`shared/clone-template-field.test.ts` 覆盖独立深拷贝、连续副本编号、表格配置、公式来源与别名、外部映射、嵌套字段；`scripts/test-field-clipboard.cjs` 覆盖三种编辑器的菜单操作、追加和只读禁用。前端构建与后端类型检查通过。组件状态测试不替代浏览器右键浮层及拖拽布局验收。

手工验收：复制带合并、修约及公式的表格，连续粘贴两次；修改副本，核对原表不变；保存重开并试录，检查各副本独立计算；报告表格核对原始记录映射仍正确。另检查空分区粘贴、跨模板确认、只读不可粘贴以及普通左键选中/拖拽不受影响。
