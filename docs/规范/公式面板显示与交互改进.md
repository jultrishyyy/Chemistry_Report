# 公式面板显示与交互改进

## 修复

原公式面板 portal 到 body，z-index 为 950，低于字段属性 Drawer，导致点击设置后面板被遮挡。现将面板挂载到当前抽屉内部（兼容 Ant Design section/content 节点），定位在抽屉底部、页脚上方；没有抽屉时回退为视口底部浮层。公式库及放弃确认位于其上方。

面板实际高度通过 ResizeObserver 测量，表格按实测高度留出滚动空间，不再固定增加 44vh 空白。下拉展开和滚动时不重设目标格；正在编辑时禁用再次打开另一个公式，避免来源格被误当作新目标。

## 操作

1. 单击结果格，点击“设置公式”。
2. 新公式默认“求和”，可改为平均、最大、最小、自定义；原有公式保持原类型。
3. 单击来源格选中，再次单击取消，只影响该格；拖动默认追加矩形区域，保留之前的零散来源，无需 Ctrl/Command。重新开始可点击“清空来源”。拖选始终以按下时的来源快照计算，回拖收缩不会残留本次扩大时新增的格子；跨入结果格时保留按下前的来源。结果格固定、来源高亮，顶部显示公式与试算结果。
4. 点击“应用公式”。未选择来源或自定义表达式为空时不可应用；原有循环引用等校验保留。

来源只在面板上方展示一组。常用计算下点击可定位，自定义公式下点击直接插入表达式；叉号移除来源。“清空来源”用于整体重新选择。表达式下方不再重复展示同一组来源按钮。

公式编辑期间始终允许点选/拖选来源，不再提供“正在选区/选择来源”开关。公式库先选择函数，再选择来源并预览确认：统计函数默认全部来源且可调整；单值函数只有一个来源时自动填入，多来源时不猜第一个；多参数函数分别设置来源或固定值，幂、根、对数、取整参数可修改。点击“插入公式”才写入表达式，保留原有表达式追加/选中文本替换规则。常量函数支持无需来源，负数常量加括号以保留优先级。

跨表引用保留在“更多设置”，不再展示全表格子按钮，改为选择表格、输入 B2 或 B2:B8 后添加；坐标解析为稳定单元格键后保存，支持边界验证并排除表头、合并覆盖格。当前表仍直接拖选，无需输入坐标。

依赖链展示及专用于展示的遍历已移除；递归求值、循环校验和精度逻辑保留，显示格式不截断中间结果，显式修约仍参与计算。自定义表达式的试算输入折叠为可选项，结果文案不再使用“试算通过”，避免被理解为真实数据检验结论。“清空”改名“清空来源”，不修改原始数据。

选择自定义会展开表达式编辑。取消或在公式面板按 Esc，若草稿发生变化则确认放弃；关闭字段属性也会提示未应用的草稿。浏览器刷新或其他页面导航的离开保护不在此次改动范围。

## 录入公式值与 PDF（2026-09-09）

自由表格在数据录入、试录测试中仅显示结果和 `ƒ`，人工修正显示橙色 `ƒ*`，不再另占一行显示“自动计算”。修正弹窗使用当前模板表格的 A1/B1 坐标，展示具体表达式，跨表来源带表格名称；内部仍保存稳定键，不通过显示坐标重新绑定。

“公式自动计算结果：”实时重新计算，忽略当前目标格的人工覆盖，但保留上游格有效的人工修正和显式修约。确认修正时记录当前自动结果，不再复用上次修正的历史结果；格式化不改变原始值。

PDF 空值的已复现原因：试样区域展开时重写了公式 sources，却没有同步重写 source_aliases 的键，自定义表达式无法取得变量值。记录与报告的区域内公式展开均同步映射来源别名及标签，表达式本身不变。

新增 `shared/free-grid-formula-display.test.ts` 覆盖按行/列试样的 PDF 源码结果、人工覆盖、地址与跨表表达式展示；`scripts/test-formula-value-dialog.cjs` 覆盖公式格紧凑显示、弹窗内容、重新计算和修正审计值。测试不等同于实际浏览器及 PDF 文件视觉验收。手工验证：分别在录入与试录中修改来源值，检查左右两侧结果一致；点击公式格核对编号/表达式；修正、再次修改来源、恢复公式，检查自动结果更新及 PDF 同步。

### 原有回归

`scripts/test-formula-panel.cjs` 通过组件事件/状态验证抽屉内挂载、默认求和、拖选来源、取消确认、保存及面板关闭。`shared/formula-grid-selection.test.ts` 验证矩形引用、合并排除、动态试样及 PDF 计算；`scripts/test-formula-range-entry.cjs` 回归行/列试样计算。

上述组件测试不替代真实浏览器布局验证。人工需检查长表滚动、窄窗口、拖动抽屉宽度、公式库/下拉不被遮挡，以及关闭属性的确认行为。未更改数据库和已保存的公式。
