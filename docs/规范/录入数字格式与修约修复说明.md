# 录入数字格式与修约修复

## 原因与处理

自由表格 Excel 导入保留原始数值，录入端原先直接将原值绑定到文本框，没有应用数字显示格式；公式求值和原始记录 PDF 已有修约处理，导致录入区看起来未生效。此次不对 Excel 原值进行破坏性截断，改为录入显示时先应用修约、再应用数字格式。聚焦编辑时显示完整原值，失焦恢复格式化显示，单纯聚焦/失焦不改写数据。

公式格显示也遵循目标格格式；没有单格设置和整表默认设置时不隐式补小数位，录入、公式预览和 PDF 均保留数值原精度。人工修正的编辑值及审计值仍使用计算值，不使用格式化字符串。空白、布尔、非数值文本不因启用修约被转换为零或数字。

## 本次记录设置

本次只读排查确认，塑料弯曲模板 v101 的“数据统计”仍保存 12 个单格格式规则，整表默认未设置不等于单格未设置。模板和录入设置现显示单格规则数量，并提供“清除整表数字格式与修约”；不自动清除数据库中已有的显式规则。清除或修改本次记录规则立即作用于已导入的原值，不需要重新导入。若旧数据在更早版本曾被截断，丢失精度不能凭空恢复。

数据录入和试录共用 FormRenderer。进入“调整结构”，点击“数字格式与修约”：

- 当前选区支持小数位、有效数字、科学计数法或不格式化，以及各种已有修约方式。
- 可切换“整表默认”；单格设置优先，可通过“选区恢复整表默认”清除覆盖。
- 设置保存于本次记录的 `__free_table_structure__`，不改模板，不额外标记新增结构；原有结构变化标记保持不变。
- 数值规则仍使用模板格键，试样区域同一模板格展开的各试样共享规则，不新增单个试样独立格式模型。
- 多格规则不一致时显示“多种格式/多种修约规则”，重新选择后统一应用。
- 设置浮层及下拉选项点击不再触发表格外部点击清除选区；真正点击其他区域仍清除选区。每次打开面板重置为“当前选区”，避免沿用上次整表操作范围。

## 验证

Excel 核对卡片新增只读“导入后表格预览”，复用 FormRenderer 的表头、合并、试样展开、数字显示及公式计算。预览使用全部有效待导入表格的模拟数据；重新框选或调整映射时立即重算，不提交、不留存附件、不递归显示上传入口。无效计划不显示部分导入结果。

自动测试 `scripts/test-free-grid-number-entry.cjs` 覆盖导入原始精度、显示/PDF一致、实例设置优先、下游公式、零值及空白文本、选区/整表设置及模板不变。另回归 Excel 导入、结构调整和行列试样公式。

`scripts/test-free-grid-number-selection.cjs` 执行组件真实外部点击处理器，覆盖浮层、下拉选项保留选区，修改格式成功持久化，以及真正外部点击取消选区。未配置公式/录入格和显式 none 覆盖整表规则另有数值回归。

人工验收：分别在试录与正式录入导入 1.245，设置五成双二位 + 小数三位，失焦应显示 1.240；聚焦应可编辑原值 1.245。修改本次规则为四舍五入应显示 1.250；保存重开与原始记录 PDF 保持一致，模板本身不变。另验证框选多格、恢复默认、新增试样继承、科学计数法与有效数字。真实浏览器焦点/光标操作仍需手工验收。
