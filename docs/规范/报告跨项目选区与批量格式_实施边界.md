# 报告跨项目选区与批量格式：实施边界

## 已完成的独立UI调整

- 删除用户缩放入口，ReportPaperViewport保留ResizeObserver驱动的自动适应宽度；拖动中间分栏不会重建编辑器、重排真实文档宽度或更新报告模型。
- 首页和每个项目使用较宽的灰蓝色分隔栏。后续分隔栏上方增加展示间隔。分隔栏是不可编辑的UI节点，非模板字段、非PDF内容，不应进入未来跨区复制/格式事务。

## 为什么不能直接让整个外层contenteditable

当前正文由多个ReportParagraphEditor/ProseMirror实例维护，各自拥有节点位置、输入法状态和局部历史。表格单元格由独立textarea及矩阵结构维护。签署区由模板字段与bottom定位等规则维护。把外层设为contenteditable，或以浏览器Range的HTML覆盖报告，会造成子编辑器状态与DOM不同步，且不能保留原始spacer、绑定、签署定位和表格合并信息。

浏览器Range全选只能解决视觉高亮，不代表编辑器能安全批量应用样式。不能将该效果标记为“全文编辑已完成”。

## 建议实现：保留存储，增加跨编辑器选区层

### 1. 选区注册与稳定定位

- 为项目标题、普通正文编辑器、表格和图片文字登记稳定地址，使用section key + group id + field id，不使用随增删变化的数组下标。
- 正文注册ProseMirror文档版本和选区from/to；首末块保留准确字符偏移，中间块选完整内容。
- 表格注册单元格稳定键和内容偏移，不把textarea DOM文本拼接成新表格；合并单元格只登记一次。
- 固定空白、签名图片和签署定位只参与可视选区定位，不转换为普通文本，不删除不重建。
- 分隔栏、拖拽手柄、行列坐标、工具栏、编辑标记均不参与选区内容。

### 2. Ctrl/Cmd+A与鼠标拖选

- 全文选择仅在报告纸面拥有焦点时触发；弹窗、管理图片、数字设置框等仍保留局部Ctrl+A。
- 单元格编辑状态下需定义“第一次选中当前格文本，再次选全文”的明确规则，避免破坏Excel录入快捷键。
- 鼠标在单个编辑器内保持原生选区；跨出编辑器后由文档选区层计算首末偏移并绘制非持久化高亮，支持向上拖选、跨滚屏自动滚动。
- 使用装饰层或ProseMirror decorations显示非焦点编辑器的选区，不修改节点内容/保存数据；输入法组合期间不切换选区。

### 3. 批量格式事务

- 首先支持字体、字号、加粗、颜色及段前/后、行距；段落属性仅修改与选区相交的段落，不能扩大为整个项目。
- 现有reportTextStyle只支持fontSize/color，必须先增加受校验的font属性，并同时接通编辑DOM、JSON清洗、复制粘贴及Typst渲染。否则字体只改容器，局部已有样式会覆盖它。
- 表格应用单元格样式，不调用“转换为自由表格”来完成字体修改；不能清除原始公式、绑定、合并或行列尺寸。
- 每个编辑器先生成不落库的变更计划。所有目标版本核对通过后，一次更新content_doc；目标被刷新、删除或修改时整次拒绝，不能修改一半。
- 格式变更只修改明确指定属性，不执行正文重新投影；空格、换行、spacer高度、编制字段及其位置必须保持。
- 统一历史记录一个事务；Ctrl/Cmd+Z一次撤回整次批量格式，而非逐个编辑器撤回。
- 对不支持的固定样式/签署内容，必须在操作前明确告知范围或拒绝，不能默默漏改后声称“全文已修改”。

### 4. 复制、输入和保护

- Ctrl+C复制实际报告内容，排除分隔栏/坐标等UI文本；文字空白与表格TSV语义分别保留。
- 在跨区选中状态按Delete、输入文字、粘贴都属于内容替换，不能借用格式事务直接处理。未实现可靠的跨块替换前必须保护内容并明确限制。
- 格式弹层打开后保留选区；批量操作不通过focus()逐个跳转子编辑器，避免光标/PDF定位来回跳动。

## 放行前必须通过的验证

1. 用MOCK-EXT-001-ALL恢复后的首页快照做只读夹具，选区建立/关闭前后content_doc逐字相等。
2. 跨首页、三个项目全选；正向/反向拖选首末半段；跨图表/空行/标题；签署区域；输入法输入中断保护。
3. 批量字体后去除允许变化的样式键，其他JSON内容必须完全相同，尤其连续空格、空段、spacer高度、编制/审核/批准字段和bottom定位。
4. 部分文字字体覆盖能在浏览器和实际Typst PDF中生效；不得以容器样式“看起来改变”代替实际选中文字样式。
5. 保存重开、连续两次修改、一次撤回/重做、选区目标被删除、异步预览返回乱序。
6. 原有单格编辑、Excel粘贴、拖选合并/拆分、图片标题与管理、方向键、图表拖拽保持通过。

## 当前状态

### 第二批：正文与图表文字的混合字体设置

在第一版基础上增加（以下范围取代第一版中“图表不参与”的限制）：

- 注册当前可直接编辑的自由表格、结果/结论/设备/多样品信息/样品描述表，以及独立图片、照片表、图库、图片分区标题。签署区、旧 data_matrix 控件和以普通字段形式显示的单样品信息仍不参与；界面显示实际参与数量，不宣称所有控件都可批量编辑。
- Ctrl/Cmd+A 选择全部已注册对象；从正文跨过图表拖到另一处正文时，途中图表以整表文字或整组图片标题参与。尚不支持从单元格内部起始的跨区字符级拖选，单元格内 Ctrl+A 保持局部行为。
- 工具栏显示正文、表格及图片标题数量，图表使用展示层边框高亮。共同显式字体/字号显示当前值，混合或未明确继承的值留空；颜色改为下拉菜单，不再把未知颜色显示成黑色。
- 混合选区仅开放字体、字号、加粗、斜体、颜色。间距和对齐禁用；“仅选正文”可保留文字选区并恢复正文间距工具，不更改内容。
- 表格只修改 table_style 与已有列/单元格样式，不调用 editReportTable，不解析/冻结数据、不触碰公式、绑定、合并、单位、修约、行高列宽或实例来源备份。补齐 table_style 的颜色/斜体在浏览器和 Typst 中的默认继承。
- 图片通过 report_image_title_style 或 image_layout.label_style 修改标题字体类属性，不改图片数量、标题文字、尺寸、裁切、布局及说明段落。
- 正文与图表的全部快照先校验，再在同一私有报告快照中执行写入，单次历史提交。无变化的设置不记历史，外部修改/撤回后旧选区失效；工具栏输入框内 Esc 也可退出选区。Ctrl/Cmd+B、I 按当前跨区选区执行，避免只改到焦点段落。
- 混合选区暂不支持复制、剪切、删除、输入替换或粘贴；会明确提示分别操作，避免只复制正文而默默遗漏图表。

验证：新增 report-bulk-font.test.ts 检查结构/绑定/公式/尺寸/间距不变及实际 Typst 字号、加粗、斜体、颜色；扩展跨区 React 测试覆盖混合选区、仅选正文、两次连续修改、一次撤回整批及工具栏内 Esc。真实浏览器拖选、滚屏及生产报告仍需手工验收。

已按确认后的阶段性范围接入第一版：可编辑正文与项目标题支持 Ctrl/Cmd+A、跨编辑器正反向拖选和批量字体、字号、加粗、斜体、颜色、对齐、段前后及行距。拖动到编辑区边缘时支持自动滚动；这部分仍需真实浏览器手工验证。

- 选区保存在 ProseMirror decoration 中，不写入报告；注册地址为当前存活编辑器及其原有稳定 ID 写入回调，跨异步文档更新即失效，不跨重载保留。
- 首末编辑器保留字符偏移。每次设置先核对全部文档版本并生成候选值，再在私有 content_doc 快照执行全部变更，单次提交、单次撤回。连续第二次改格式可以沿用选区。
- 字体属性经过白名单清洗，同时进入浏览器文字标记、JSON 和 Typst；混合或继承值不冒充统一值显示。
- 单区正文字体按钮同时移入正文共享工具栏，改为修改所选文字的字体标记，取消仅修改分区容器字体的旧路径；防止批量设置后局部修改被内联字体覆盖。
- 第一版不覆盖表格单元格、图片标题、签署区和其他非正文控件，工具栏及全选提示明确说明范围。单元格输入中的 Ctrl+A 保持原有局部语义，尚未做第二次按键升级全文。不能将本版描述为“整个报告所有内容统一改格式已完成”。
- 跨区 Delete、输入、剪切和粘贴暂时阻止，并提示 Esc 退出后局部编辑；复制只输出所选正文，不带分隔栏等 UI。没有跨块删除或替换能力。
- 未修改任何数据库报告或重新应用模板；源模板、图表、签署定位仍按原路径保存。旧字段转正文沿用既有编辑回调并保留源字段备份，不进行全报告扁平化迁移。
