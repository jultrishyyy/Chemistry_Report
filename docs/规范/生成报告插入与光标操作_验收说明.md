# 生成报告：插入与光标操作

## 本批修改

- 插入菜单只保留表格、图片。正文仍通过 Enter 换行；图表边缘仍可按 Enter 建立文字输入位置，内部段落插入逻辑未删除。
- 新表格采用不带独立表头的 free_grid。行数就是总行数，3×3 为 3 行 3 列，初始单元格为空；支持 1×1。只改变新建表格，不迁移现有模板或报告表格。
- 图表选中后第一次左/右键定位到对应边缘；同方向再按一次进入相邻内容，上/下键直接尝试移动。没有相邻内容时保留边缘光标，不凭空增加段落。
- 图表上下边缘点击优先定位已有内容；框外空白按上/下半区定位。定位本身不写入报告。
- 图表边缘删除检查当前一侧的空白；整块选中、尚无边缘光标时沿用删除上方空白。仍禁止通过此逻辑删除非空正文、图表或签署内容。
- 报告表格最上/左边界可返回前文，原有最下/右边界可进入后文。单元格处于文字编辑状态时仍保留格内光标行为；修饰键及输入法不触发边界跳转。

## 验证

1. 打开报告副本，检查插入菜单不再出现“文字段落”；直接在正文按 Enter 输入。
2. 分别插入 1×1、3×3、2×5，检查左侧与 PDF 实际尺寸；首行与其他格子一样编辑，无额外“列1”等占位标题。
3. 图表前后各放正文和一个空段。测试左右连续按键、上下移动、边缘点击、Enter，以及前后空白删除，确保另一侧正文不变。
4. 在表格首格的选中状态按上/左，在末格按下/右；进入编辑状态后确认方向键仍能编辑格中文字。
5. 撤回、保存重开；检查已有报告表格、首页留白及编制区域未变化。

自动检查覆盖键盘导航、合并格、修饰键保护、光标决策、插入尺寸及实际 Typst 表格格子数。真实浏览器坐标点击、滚动和输入法需按以上步骤手工验收。
