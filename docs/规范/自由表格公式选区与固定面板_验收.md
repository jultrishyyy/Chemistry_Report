# 自由表格公式选区与固定面板

## 本次改进

- 自由表格公式编辑面板固定在编辑区底部，详情可收起，应用/取消和公式预览始终可见；表格预留底部滚动空间。
- 点击选择单格、拖拽选择矩形；Ctrl/Command 追加不连续区域。重新普通拖拽替换当前来源，回拖可缩小选区。
- 引用区域为蓝色、目标格为橙色；点击目标和来源标签定位，标签叉号删除来源。
- 普通矩形在平均/求和等公式中显示为 B2:C6，实际保存仍是稳定格子标识，不把位置字符串作为取数键。
- 表头不计入公式，合并覆盖格不重复计入。选区包含目标格时拒绝该区域并提示；保存时检查间接循环引用。
- 当前表格的带外平均/求和/最大/最小汇总可选择“随试样增减”。关闭时仅取原选中试样，已删除试样仍排除；历史公式缺省保持原来的动态行为。
- 试样引用方式同步到录入计算、原始记录 PDF、报告公式取数和迁移映射兼容层。

## 边界

- 四则运算拖选只增加来源变量，不擅自把区域求和；用户仍需填写表达式或从公式库选择聚合函数。
- 跨表来源目前保留原有点选入口；本次拖拽区域主要作用于当前表格。固定试样范围仅支持当前表格汇总，不新增跨表固定范围模式。
- 数据录入中的“人工修正公式结果”仍只修正本条记录，不新增修改模板公式的权限。
- 未改动现有模板数据库，也未批量重写已保存公式。迁移公式的历史精度设置保持原有运行行为；重新编辑应用时仍沿用现有公式编辑器的保存规则。

## 手工验收

1. 模板中选中汇总格，设置公式为求和或平均；面板应位于编辑区底部。
2. 向下滚动到数据区，拖动选中 2×3 区域，再往回缩小。确认来源数量和蓝色选区同步。
3. 按 Ctrl/Command 再选另一块区域，确认此前来源保留；重复经过相同格子不重复计数。
4. 选含表头和合并格的区域，确认不计表头、不重复计算合并覆盖格；将目标格包含进选区应出现提示。
5. 收起详情，点击来源标签及目标按钮确认可定位；点叉号移除来源。
6. 拖到滚动容器边缘，确认纵向/横向滚动；松开鼠标后停止。
7. 点取消后重新打开，旧公式应不变；点应用后保存、重新打开，来源和计算方式应保留。
8. 当前表格汇总分别开启/关闭“随试样增减”，试录增加一个高辨识度试样值，再删除中间试样；核对录入值、原始记录 PDF 和报告结果。

## 自动检查

选区单元测试覆盖正反拖选、缩小、合并去重、坐标显示；计算测试覆盖固定/动态引用及删除；SSR 验证按行/列试样的录入计算。另运行原有表格、试样、报告映射和迁移回归测试、前端构建与服务端类型检查。

尚无真实浏览器鼠标交互自动化，固定面板位置、拖拽滚动与小屏布局仍需按上述步骤人工验收。
