## 1. 系统用途和完整业务流程

本系统用于把“原始记录模板设计—实验室数据录入—审核—报告模板映射—报告生成—报告审核与归档”连接成一条完整流程。原始记录保留检测过程数据，报告模板决定这些数据在最终报告中的位置和版式，生成后的每份报告仍可在权限允许时单独调整。

推荐按以下顺序使用：

1. 在**原始记录模板**中设计基本信息、试验结果、图片、结论、签字等内容。
2. 将模板提交审核，审核通过后成为可用于录入的生效版本。
3. 在**实验室录入**中按订单、样品和测试项目填写数据，上传图片和附件，然后提交审核。
4. 在**报告模板**中创建首页模板和项目模板，设置主机厂、项目组和数据映射。
5. 在**生成报告**中检查原始记录，选择首页模板，按报告编号生成报告。
6. 在报告编辑器中调整文字、表格、图片、分页、签发区域等内容，预览 PDF，提交报告审核。

系统顶部的主要菜单如下：

| 菜单 | 主要用途 |
|---|---|
| 原始记录模板 | 设计原始记录、维护版本、派生子模板、组织项目组 |
| 实验室录入 | 按订单、样品、项目填写和审核原始记录 |
| 报告模板 | 创建首页模板、项目模板，设置主机厂和映射 |
| 生成报告 | 查看录入进度、退回记录、生成和编辑报告 |
| 设备库 | 维护设备信息，供记录和报告引用 |
| 用户管理 | 管理角色、权限、账号状态和角色申请，仅管理员可见 |

## 2. 登录、导航和基本操作

### 2.1 登录和账号

使用单位提供的账号登录。若系统对接了外部统一账号，首次登录会在本系统建立本地用户资料。新用户可能暂时没有业务角色，此时可从右上角用户菜单进入**我的角色与权限**，查看已有权限或申请角色，等待管理员审核。

### 2.2 权限和状态

同一页面上，不同人员看到的按钮可能不同。例如：

- 模板设计人员可以创建、编辑和提交模板；审核人员可以批准或驳回。
- 实验室工程师可以录入；记录审核人员可以审核或退回。
- 报告编制人员可以生成和编辑报告；报告审核人员负责审核。
- 已提交审核、已审核或历史版本通常为只读状态。

如果无法编辑，先检查页面提示中的状态，再检查当前账号是否拥有相应权限。协同编辑页面若显示他人正在编辑，应等待对方结束编辑；完成操作后点击**结束编辑**，让系统保存并释放编辑权。

### 2.3 通用界面习惯

- 列表支持搜索、状态筛选、分页和每页条数调整。
- 编辑器通常为左侧编辑、右侧 PDF 预览。修改后等待预览刷新再核对分页。
- 带“版本历史”的模板可查看历史内容、版本差异和操作日志。
- 浏览器刷新会重新加载已保存内容。尚未保存的临时选择、页面内复制缓存等可能丢失。

## 3. 原始记录模板

### 3.1 创建方式

进入**原始记录模板**，点击**新建**。可选择以下方式：

| 创建方式 | 适用场景 | 后续关系 |
|---|---|---|
| 空白创建 | 新方法或全新格式 | 独立模板 |
| 复制现有模板 | 只想复用当前内容，之后各自维护 | 完全独立，不建立母子关系 |
| 派生子模板 | 多个方法共享基础结构，希望保留来源和后续同步关系 | 建立母模板—子模板关系 |

**复制**与**派生**不是同一功能。复制后，源模板的后续修改不会传入副本；派生会记录母模板、母版本和字段对应关系，可在后续同步时识别同源字段。

创建时可填写模板名称，并按需要加入原始记录项目组。项目组是分类和批量管理容器，不等同于母子关系。

### 3.2 编辑器结构

模板编辑器通常包含：

- 顶部：保存草稿、结束编辑、提交审核、版本历史、派生关系等操作。
- 左侧：页面结构、分区、字段和自由表格。
- 右侧：PDF 预览，可切换空白预览、示例数据预览或试填预览。

建议先搭建分区，再添加字段，最后统一处理字体、间距和分页。这样比逐项反复调版更稳定。

预览模式的用法：

- **示例数据**：系统自动填充模拟值，适合检查内容较满时的换行和分页。
- **空白**：显示未填写记录的样子，适合检查空表、留白和默认文字。
- **试填**：打开真实录入控件，可测试选择项、公式、增删试样行列和输入体验。试填数据只用于本次测试，关闭后丢弃，不会生成记录，也不会修改模板。

### 3.3 受控登记

模板建立并保存后，可点击**受控登记**填写：

- 受控号。
- 发布日期。
- 实施日期。

这些信息印在该模板生成的原始记录顶部，并随当前生效版本冻结。模板换版时应按单位文件控制制度确认是否需要新的受控号或日期。受控登记属于模板管理信息，不要用普通静态文字代替，否则无法随版本追溯。

### 3.4 分区

分区是一组相关字段，常用预设包括：

- **基本信息**：委托单号、样品编号、样品描述等。
- **试验结果**：通常包含自由表格。
- **图片记录**：检测前、检测中、检测后等图片。
- **结论**：项目名称、判定要求、限值和结论。
- **检测与审核信息**：检测人、检测日期、审核人等。

每个分区可执行：

1. 修改分区标题，或隐藏标题。
2. 上移、下移和删除。
3. 设置单列或双列布局。
4. 调整分区标题字体、字号、粗细、对齐和间距。
5. 设置**从新页开始**。当某个完整模块应另起一页时使用。
6. 调整字段名与字段值的排布，例如紧凑排列、固定标签宽度等。

删除分区会连同其中字段一起删除。正式模板中执行前应确认版本历史中已有可恢复版本。

### 3.5 字段类型和用途

点击分区中的**添加字段**，按业务含义选择字段类型。

| 字段类型 | 用途和主要设置 |
|---|---|
| 单行文字 | 编号、名称、短说明；可设置默认值、必填、单位和公共字段 |
| 多行文字 | 样品描述、试验条件、备注等长内容；录入时可换行 |
| 数字 | 数值数据；可设置单位和显示方式 |
| 日期 | 单个日期 |
| 日期范围 | 开始日期和结束日期，主要用于报告字段 |
| 单选 | 从固定选项中选择一个，可允许自定义项 |
| 多选 | 选择多个选项，可允许自定义项 |
| 图片 | 上传一张或多张图片，并设置图片布局 |
| 自由表格 | 设计复杂表头、试样区、公式、单位和 Excel 导入规则 |
| 设备引用 | 从设备库选择设备，可选择一个或多个 |
| 静态文字 | 固定说明、标准条款等无需录入的数据 |
| 空白间隔 | 留出垂直空间，用于排版 |

系统可能显示针对首页或项目报告的专用字段，如样品信息表、检测结论表、原样照片表、样品描述表、设备表等。这些应在对应的报告模板中使用。

### 3.6 字段通用设置

选中字段后可设置：

- **字段名称**：界面和 PDF 上显示的标签。
- **字段标识/编码**：数据匹配使用的稳定标识。已经用于公共字段或报告映射后，不建议随意修改。
- **必填**：开启后，未填写时不能正常提交审核。
- **默认值**：新建记录时自动带出，录入人员仍可按权限修改。
- **单位**：固定单位或可选单位。
- **说明文字**：提示录入人员如何填写。
- **显示/隐藏字段名**：只显示内容或同时显示标签。
- **整行显示**：让字段占满当前行，适合长文字和图片。
- **公共字段/允许其他记录拉取**：允许同订单、同样品、同项目的其他原始记录复制此值。
- **文字格式**：标签和内容可分别设置字体、字号、粗体、斜体、颜色和对齐。
- **块级排版**：段前、段后、字段间距、行距和分页。

基本信息分区中的普通字段创建时通常默认开启公共字段。试验结果、公式、图片、结论、签字、动态选项和静态内容不会作为普通公共字段拉取。

### 3.7 选择、复制和粘贴字段

模板编辑器中的字段支持页面内复制：

1. 选中字段，右键选择**复制字段**，或在未编辑文字时使用 `Ctrl/Cmd + C`。
2. 选中目标字段，右键选择粘贴到目标后方；也可以粘贴到指定分区末尾。
3. 系统会为副本生成新的字段 ID，避免两个字段共用同一身份。

复制会保留字段样式、默认值、选项、表格结构、合并关系、试样区、公式和 Excel 设置。自由表格内部引用自身单元格的公式会随副本更新；引用其他表格或外部字段的公式和映射应重新检查。

限制如下：

- 只能在兼容的编辑器和分区中粘贴。例如图片应放入图片分区。
- 结论和签发等唯一角色字段可能不能重复添加。
- 输入框内的文字复制、表格单元格复制和浏览器原生复制仍按普通方式工作。
- 页面内字段复制缓存通常只在当前标签页本次会话中有效，刷新或关闭后需重新复制。

### 3.8 结论分区

结论分区的**判定要求**默认采用单选类型，默认选项为：

- 标准要求
- 客户要求

可以开启自定义选项，让录入人员补充其他判定依据。项目名称、限值、判定要求和结论各有不同业务角色，不要仅靠显示名称互换用途，否则报告结论表可能无法正确识别。

### 3.9 图片分区

图片分区可设置：

- 共用标题或每张图片独立标题。
- 每行图片数量。
- 图片宽度、高度、旋转和压缩质量。
- 粘连框或独立框。粘连框适合连续的“检测前/中/后”表格；独立框适合各自成块的照片。
- 内边距、奇数图片单独占行、跨页重复表头等。

图片较多时，PDF 会按可用页面空间分页。不要单纯依靠固定大高度塞入一页，应在右侧 PDF 中核对实际分页。

### 3.10 整体排版

文档级设置通常包括：

- 正文字体和字号。
- 文档标题、分区标题与正文的字号比例。
- 字段间距、分区间距、段前和段后。
- 标签粗细、标签宽度和对齐。
- 表格边框、页面左右边距和上下边距。

系统内置常用中文和英文字体。最终效果以右侧 PDF 为准，因为浏览器编辑区和 PDF 的字形度量可能略有差异。统一模板时，建议先选定字体和正文尺寸，再调整表格列宽和分页。

## 4. 自由表格完整操作

自由表格是原始记录和项目报告中最重要的结构化编辑组件，可实现复杂表头、逐试样录入、合并单元格、单位、公式和 Excel 导入。

### 4.1 建表和选择

添加**自由表格**后，可设置初始行数和列数。模板设计阶段最多支持 50 行、30 列；具体业务中应避免创建大量无用空行。

选择方式：

- 单击格子：选择一个单元格。
- 按住鼠标拖动：框选一个矩形区域。
- 单击左侧行号：选择整行。
- 单击上方列标：选择整列。
- 拖动行或列的控制点：调整顺序。
- 拖动边缘：调整行高或列宽。
- 使用缩放：仅改变设计视图大小，不改变最终 PDF 尺寸。

对选中区域可执行合并、拆分、插入行列、删除行列、批量配置和格式设置。合并后只保留主格的数据角色；合并前应确认其他格子没有需要保留的数据。

### 4.2 单元格角色

双击格子、右键选择设置，或框选后点击批量设置，可配置角色：

| 角色 | 说明 | 示例 |
|---|---|---|
| 表头 | 参数名称或标题，不供录入 | 试样编号、透光率、平均值 |
| 固定文字 | 模板预置内容，录入时仍可按业务修改 | 检测条件、说明文字 |
| 输入 | 由实验室人员填写 | 每个试样的实测值 |
| 公式 | 由其他单元格自动计算 | 平均值、最大值、判定结果 |

一个有文字的表头或固定文字格无需再绑定为输入格。报告映射时，固定文字和表头也可作为来源。

### 4.3 数据类型、单位和显示

输入格可设置：

- **文字**：自由输入。
- **数字**：用于计算和数字格式化。
- **选择**：配置候选项，可按需要允许自定义输入。
- **试样序号**：位于试样区时可按新增试样自动编号。

单位可使用固定单位，也可提供多个单位供录入人员选择。对数字还可设置小数位、有效数字或科学计数法等显示方式。

**显示格式**只改变呈现；**舍入规则**会改变公式继续使用的数值。需要严格执行标准中的修约规则时，应明确配置修约方式和位数，并用边界值试算后再发布模板。

### 4.4 设置试样区域

试样区域告诉系统哪些行或列会随实际试样数量扩展。

操作步骤：

1. 先完成表头和至少一行或一列示例数据结构。
2. 用鼠标框选连续的数据格，不要包含表头。
3. 点击**设置试样区域**。
4. 选择方向：
   - **每行一个试样**：新增试样时向下增加整行。
   - **每列一个试样**：新增试样时向右增加整列。
5. 检查试样序号、输入格、单位格和公式是否跟随扩展。

一个试样区域可以包含多列参数或多行参数。例如每行一个试样时，可将“序号、长度、宽度、结果”四列的数据区域整体框选。录入时新增试样会复制整组角色、格式和公式。

同一张来源自由表格通常设置一个连续试样区域。如果方向或范围设置错误，先清除试样区域，再重新框选。表头不应放入试样区；跨表头和数据区的合并单元格会影响分页和扩展，应先拆分。

### 4.5 多个试样和空试样

录入时可通过**新增试样行/列**扩展试样区，也可删除不需要的试样。报告生成只使用实际有数据的试样行或列；完全未填写的预留试样不会作为有效数据带入报告。

如果表格右侧或下方有平均值、结论等合并格，模板中应让这些格子位于试样扩展区之外，并正确设置跨行或跨列关系。报告按实际试样数扩展时，这些汇总格会保持为对应范围的合并格。

### 4.6 公式

选择目标格，将角色设为**公式**，然后在公式栏输入以 `=` 开头的表达式。常见写法：

```text
=AVERAGE(B2:B6)
=SUM(C2:C6)
=MAX(D2:D6)
=IF(B2>10,"合格","不合格")
```

可用能力包括：

- 基本运算：`+`、`-`、`*`、`/`、`^`、`%` 和括号。
- 比较与逻辑：`>`、`<`、`>=`、`<=`、`=`、`<>`、`IF`、`AND`、`OR`、`NOT`、`IFERROR`。
- 汇总统计：`SUM`、`AVERAGE`、`MIN`、`MAX`、`COUNT`、`PRODUCT`、`MEDIAN`、标准差和方差。
- 数学函数：`ABS`、`ROUND`、`ROUNDUP`、`ROUNDDOWN`、`CEILING`、`FLOOR`、`MOD`、`POWER`、`SQRT`、`EXP`、`LN`、`LOG`、三角函数等。
- 同表引用：`B2`、`B2:B8`。
- 跨表引用：在公式编辑状态选择其他自由表格中的单元格，系统会保存稳定引用；界面可显示类似 `'表格名称'!B2` 的表达式。

编辑公式时按 `Enter` 完成，按 `Esc` 取消。系统会检查循环引用；例如 A1 引用 B1、B1 又引用 A1 时不能保存。

逐试样公式应开启**跟随试样**或使用试样区内的对应公式格。这样新增试样行/列时，引用会随位置变化。汇总公式通常放在试样区外，引用整个试样数据范围。

计算时保留足够精度，显示格式在最后应用。若要求每一步先修约再参与下一步运算，应在中间公式中显式使用 `ROUND` 等函数或配置舍入规则。

### 4.7 表头重复和分页

可指定连续的顶部行作为重复表头。表格跨页时，PDF 会在新页重复这些行。表头行必须连续，且合并单元格不能跨越“重复表头”和“数据区”的边界。

### 4.8 自由表格格式

可对整表、整行、整列或选中格设置：

- 字体、字号、粗体、斜体、颜色。
- 左对齐、居中、右对齐和垂直对齐。
- 行高、列宽、边框和内边距。
- 表格标题与图注。标题位于表格上方，图注可放在上方或下方。
- 清除单元格格式，使其恢复整表默认格式。

先设置整表默认样式，再对少量单元格覆盖，可减少后期维护工作。

## 5. 公共字段和多测试方法复用

### 5.1 适用场景

一个订单中的同一项目可能使用多个测试方法，因此会关联多个原始记录模板。它们的基本信息相同，但试验结果、图片和结论不同。公共字段可避免重复填写相同信息。

### 5.2 完整示例

假设建立测试项目“耐候性”，包含三个测试方法：

- 方法 A：氙灯老化，对应原始记录模板 A。
- 方法 B：紫外老化，对应原始记录模板 B。
- 方法 C：湿热循环，对应原始记录模板 C。

三个模板都包含以下基本信息，并使用相同的字段标识、类型和单位：

- 委托单号 `service_no`
- 样品编号 `sample_no`
- 样品状态 `sample_condition`
- 环境温度 `environment_temperature`，单位 ℃
- 环境湿度 `environment_humidity`，单位 %RH

这些字段开启**公共字段/允许其他记录拉取**。数据录入时，一个样品的“耐候性”项目会显示三份原始记录。操作如下：

1. 打开模板 A 的记录，填写公共基本信息和方法 A 的专有结果，保存。
2. 打开模板 B，点击**拉取公共字段**。
3. 选择模板 A 对应的已填写记录作为来源。
4. 在预览中检查可匹配字段、现有值差异和未匹配原因。
5. 空白目标字段可直接填入；若目标已有值，只有明确勾选替换后才会覆盖。
6. 确认后再填写方法 B 的试验结果。
7. 模板 C 重复上述操作。

拉取后，B、C 中的值成为各自记录的独立快照。以后修改 A 不会自动改写 B、C，如需同步应再次拉取并确认替换。

### 5.3 匹配条件

公共字段拉取通常要求：

- 同一订单、同一样品、同一测试项目。
- 来源是该项目关联的另一份原始记录模板。
- 来源记录已存在且未取消。
- 来源和目标字段都开启公共字段。
- 字段标识、字段类型一致；单位及选择项配置兼容。

自由表格、图片、公式结果、结论和签字审核字段属于方法专有内容，不应依靠普通公共字段拉取。

### 5.4 项目组与公共字段

可把同一测试项目的多个模板放入同一个原始记录项目组，方便查找、批量管理和按稳定字段标识同步结构。项目组本身不会自动把所有字段变成公共字段；仍需在各模板中正确设置字段标识和公共属性。

## 6. 模板版本、审核、母子关系和项目组

### 6.1 草稿和审核

模板修改先保存为草稿。完成后：

1. 点击**结束编辑**，确保自动保存完成并释放编辑权。
2. 点击**提交审核**，可填写本次修改说明。
3. 审核人员查看内容和差异，选择通过或驳回。
4. 通过后成为当前生效版本；驳回后修改人员可继续调整再提交。

已提交审核的版本通常只读。提交人可在权限允许时撤回为草稿。

### 6.2 版本历史

点击**版本历史**可查看：

- 每个版本的状态、时间和操作者。
- 版本差异。
- 指定历史版本的 PDF 或结构内容。
- 创建、保存、提交、审核、同步、回退等操作日志。

恢复历史版本时，系统可能重置当前草稿，或基于历史版本创建新的回退版本。弹窗会说明影响，应确认当前未提交修改是否需要保留。

### 6.3 派生子模板

在已建立的模板上点击**派生子模板**，填写子模板名称并选择需要继承的分区。派生后：

- 子模板保留母模板及母版本信息。
- 同源字段具有映射关系。
- 子模板可以增加自己的专有字段。
- 母模板后续变更可按系统提供的同步功能形成子模板草稿，审核后生效。
- 同步时应检查子模板专有字段、跨表公式、报告映射和分区顺序。

需要长期共享和追踪结构时使用派生；只需要一次性副本时使用复制。

### 6.4 项目组

项目组用于把相关模板集中管理。例如可建立“耐候性测试组”，放入氙灯、紫外、湿热等原始记录模板。可在组内新建模板、加入已有模板、移出模板和同步兼容字段。

项目组不是数据记录，也不会替代母子关系。删除项目组采用申请、审核的归档流程；批准后只解除分类关系，模板和历史数据仍保留。

### 6.5 重命名、删除和归档

模板名称可在有权限时修改，重命名不会改变字段标识和历史版本。删除模板需要提交删除申请并由具备审核权限的人员批准；批准后采用归档方式从日常列表隐藏，版本、操作日志和已经使用该模板录入的数据仍保留。存在正在审核的版本时，应先完成审核或撤回，再申请删除。

## 7. 实验室数据录入

### 7.1 进入记录

进入**实验室录入**，按订单号、状态或负责人查找任务。打开订单后，以“样品 × 测试项目 × 原始记录模板”为单位进入记录。

当一个项目关联多个原始记录模板时，同一个项目会出现多份记录，代表不同测试方法。每份记录分别保存、审核，但可使用公共字段拉取减少重复填写。

### 7.2 录入状态

常见状态包括：

- 未录入或草稿：可编辑。
- 待审核：已提交，通常只读。
- 已审核：作为报告生成的有效来源。
- 已退回：按退回意见修改后重新提交。

系统支持自动保存。进入可编辑记录后先点击**开始编辑**；编辑过程中观察保存状态。离开前点击**结束编辑**，避免其他人长时间无法取得编辑权。

### 7.3 填写字段

- 必填项应全部填写。
- 单选、多选和单位按模板设置选择。
- 日期使用日期控件。
- 多行文字可直接换行。
- 设备引用从设备库搜索并选择。
- 公式格和表头为受保护内容，不需要手工输入。

右侧 PDF 会随录入刷新，用于检查真实打印效果。若发现结构错误，应由模板管理员修改模板并走版本审核；录入页面提供的局部结构调整主要用于本次记录。

### 7.4 录入时调整自由表格

在权限允许时可：

- 新增或删除试样行/列。
- 增加临时普通行/列并调整结构。
- 修改行高、列宽和部分排版。
- 在输入格之间使用方向键或 `Enter` 移动。
- 在支持多行的格子中使用 `Shift + Enter` 换行。

临时新增的非试样行列可能没有预设报告映射。生成报告时系统会提示核对，可在报告编辑器的**原始数据**中复制补充，或回到项目模板增加正式映射。

### 7.5 拉取公共字段

目标记录打开后点击**拉取公共字段**，选择来源记录，核对匹配预览，再确认填入。已有内容不会在未确认的情况下被静默覆盖。

### 7.6 提交和退回

填写完成后保存并提交审核。审核人员可查看记录及 PDF，选择通过或退回，并填写意见。报告编制时若发现已审核数据有误，也可以从报告界面退回原始记录；记录重新审核通过后，报告应刷新项目数据或重新生成相应内容。

## 8. Excel 导入、复制和粘贴

### 8.1 模板中的 Excel 设置

要让某个自由表格支持 Excel 导入：

1. 在原始记录模板中选中自由表格。
2. 开启**允许 Excel 导入**。
3. 填写**Sheet 名称**。应填写 Excel 文件中完全对应的工作表名称，尤其是文件含多个 Sheet 时。
4. 确认系统表格中的参数表头与 Excel Sheet 中的参数名称一致。

例如系统表头为“透光率（%）”，Excel 中也应使用同样名称。系统可容忍部分空格、大小写、全角半角和合并表头造成的差异，但不同别名、不同单位或完全不同的命名无法可靠自动匹配。

### 8.2 导入 Excel

在数据录入页面点击**导入 Excel**并选择 `.xlsx` 文件。系统会依次引导：

1. 选择目标自由表格和 Sheet。
2. 指定数据按行还是按列排列。
3. 框选 Excel 中的候选数据区域。
4. 检查参数与系统表头的映射。
5. 预览将新增的试样、覆盖的值和被跳过的格子。
6. 对所有启用导入的目标表格完成检查或明确跳过。
7. 一次确认写入。

导入确认前取消，不会部分写入。空白 Excel 单元格默认不会清空系统已有值；表头、公式、序号和受合并保护的格子不会被覆盖。系统不会自动创建模板中不存在的新参数，也不会自动换算不同单位。

导入的 Excel 文件会作为原始资料留存在附件中，便于追溯。

### 8.3 导入识别不正确时

先在导入卡片中调整：

- Sheet 是否选对。
- 数据方向是否正确。
- 框选区域是否包含多余标题或备注。
- 参数映射是否对应正确。
- Excel 合并单元格是否造成表头错位。

仍不能正确识别时，使用 Excel 复制粘贴：

1. 在 Excel 中框选连续单元格并复制。
2. 在系统自由表格中单击左上角目标输入格。
3. 粘贴后检查覆盖提示。
4. 系统按制表符和换行把内容填入对应网格，并跳过公式、表头和受保护格。

### 8.4 文件限制建议

建议使用无密码、无宏的 `.xlsx` 文件，避免旧版 `.xls`。超大工作簿可能被系统拒绝；当前导入保护上限通常包括文件约 10 MB、单 Sheet 约 10,000 行和 200 列。客户模板应只保留实际数据区域。

## 9. 图片和附件

### 9.1 图片录入

在图片字段或图片分区中点击上传。可执行：

- 一次上传一张或多张图片。
- 修改图片标题。
- 调整图片顺序。
- 设置显示宽度和高度。
- 每次旋转 90°。
- 调整压缩质量，平衡清晰度和 PDF 大小。
- 删除或替换图片。

手机或平板等触控设备可选择相册，也可直接调用相机拍照上传；电脑端只显示文件上传，不提供直接拍照按钮。系统也提供移动端图片上传页面，按订单、样品、项目和模板定位后上传，适合现场拍摄。

### 9.2 图片排版

根据模板配置，图片可每行一张或多张，可使用共用标题或单图标题。粘连框适合连续图片表；独立框适合单图说明。图片数量超过当前页容量时会自动分页，跨页共用表头可按模板设置重复。

### 9.3 通用附件

页面底部附件区可上传任意业务文件，例如原始 Excel、仪器导出文件、PDF、压缩包或说明文件。支持多选上传，并显示文件名、大小和类型标记。

常用操作：

- 点击文件名或下载按钮下载。
- 勾选多个文件后批量下载。
- 删除单个或批量删除附件。
- 已审核记录通常只允许查看和下载，不允许删除。

部分附件操作要求记录已有草稿 ID，因此首次进入空记录时可先保存草稿再上传。删除附件不可恢复，删除前应确认已有其他留档。

## 10. 设备库

进入**设备库**维护实验室设备。设备信息可包括设备名称、型号、管理编号或资产编号、溯源日期、有效期等。

在原始记录模板中使用**设备引用**字段后，录入人员可按设备名称、管理编号或资产编号搜索，选择一个或多个设备。报告项目模板中的设备表可自动展开已选设备的名称、型号、编号和溯源信息，减少重复填写。

设备信息发生变化时，应先在设备库维护。历史记录和历史报告按其保存的快照查看，不应为了修改旧报告而改动当前设备主数据。

## 11. 报告首页模板和项目模板

### 11.1 两种模板的区别

进入**报告模板**后可切换：

| 模板类型 | 内容 | 使用范围 |
|---|---|---|
| 首页模板 | 报告封面、样品信息、检测结论、声明、签发区等 | 应用到每个报告编号的首页 |
| 项目模板 | 某个测试方法的结果表、设备、图片、结论等 | 应用到具体样品和项目明细 |

两类模板均有草稿、审核、版本历史、复制和派生能力。只有审核生效的模板可用于正式生成。

### 11.2 主机厂

创建首页模板或项目模板时可关联主机厂，也可在模板列表的**主机厂**列点击修改。主机厂库由有权限人员维护名称、简称、类别和备注。

生成报告时，如果选择了带主机厂的首页模板，系统会优先推荐同一主机厂的项目模板。推荐只负责默认选择，编制人员仍可逐项目改选。

### 11.3 报告项目组

可以建立报告项目组，把同一主机厂或同一套报告格式的首页模板和项目模板放入一组。例如“奇瑞报告模板组”可以同时包含奇瑞首页和多个奇瑞项目模板。

项目组主要用于管理、筛选和组内创建，不是必填项。模板仍需自行关联主机厂和配置映射。项目组不自动把首页模板的数据结构继承给项目模板，也不代替模板审核。

### 11.4 创建首页模板

可空白创建或复制已有首页。常用首页专用字段：

- 样品信息表。
- 检测结论表。
- 原样照片表。
- 样品描述表。
- 报告编号、校验码、签发日期、委托单位等普通映射字段。
- 报告声明、资质说明等静态或接口字段。
- 签发/签字分区。

首页没有唯一的当前测试项目，因此不要把只属于某一个项目的来源直接放入普通首页字段。跨项目内容应使用样品信息表、检测结论表等汇总字段。

### 11.5 创建项目模板

创建项目模板时关联对应的原始记录模板。系统可直接从原始记录模板拉取分区、自由表格、图片和字段，并预先配置同源映射。完成拉取后仍应检查：

- 是否需要显示全部原始记录字段。
- 表格标题和表头是否适合报告。
- 试样方向和试样参数映射是否正确。
- 图片分区是否映射到正确来源。
- 设备、结论、单位和审核信息是否需要展示。
- 每个项目是否另起一页。

后续原始记录模板或项目模板更新后，已生成报告不会无条件自动重写人工调整。可在报告编辑器中使用**刷新项目模板**，确认后重新拉取最新生效模板和记录。

## 12. 报告字段映射

映射决定报告中的字段从哪里取值。选中报告模板字段或自由表格区域，点击添加或修改映射。

### 12.1 常用来源

| 来源分类 | 示例 |
|---|---|
| 固定值 | 固定标题、固定说明 |
| 订单 | 订单号、委托方、收样日期、客户地址、报告份数、备注等 |
| 报告样品 | 样品名称、样品序号、型号规格、样品列表 |
| 当前样品 | 当前项目对应样品的各项信息 |
| 测试项目信息 | 项目名称、标准、方法、条件、制样要求、限值、负责人和日期 |
| 报告信息 | 报告编号、首页编号、校验码、签发日期、单位名称、地址、电话、传真、网址、声明 |
| 系统时间 | 当前日期或时间 |
| 原始记录字段 | 普通字段、检测人、检测时间、审核人、审核时间 |
| 原始记录表格 | 固定格、表头、单位、公式结果、逐试样数据和汇总值 |
| 原始记录图片 | 对应图片分区或图片字段 |

校验码、签发区域备注等需要使用接口提供值时，应明确选择相应的**报告信息**来源，而不是填写固定示例文本。

### 12.2 普通字段绑定

1. 选中目标字段。
2. 点击映射按钮或空格中的 `+`。
3. 在来源树中选择具体数据。
4. 如有单位，选择跟随来源单位、字段单位或手工单位。
5. 保存并查看右侧示例 PDF。

字段中已有模板文字时，映射标记不会在正文下重复显示；映射状态可通过链接图标或设置面板检查。

### 12.3 自由表格的固定格绑定

表头、说明或单个汇总格可逐格绑定。先框选单格或连续区域，再选择来源。框选多个格时可使用批量绑定，将顺序一致的数据来源依次对应到目标格。

### 12.4 试样行/列绑定

报告项目自由表格要显示多个试样时，不需要逐格绑定每个试样：

1. 在项目模板中用鼠标框选需要随试样扩展的一片数据格，可以是一列、多列、一行或多行。
2. 点击**选择试样行/列来源**。
3. 在映射面板中选择原始记录自由表格的逐试样行或逐试样列。
4. 选择参数表头，例如“试样编号”“透光率”等；多个目标参数按顺序对应多个来源参数。
5. 确认后，系统会建立整行或整列的试样映射，并自动识别目标试样区域。

如果来源是“每行一个试样”，报告目标通常也按行展开；来源是“每列一个试样”时通常按列展开。生成时系统按原始记录中实际有数据的试样数量扩展，空白预留试样不带入。

### 12.5 图片映射

从原始记录模板拉取项目模板时，图片分区会默认映射到同源图片分区。仍应打开图片设置核对标题方式、每行数量、尺寸、粘连或独立框、分页表头等。

若后续新加图片分区，需在项目模板中补充映射并让模板审核生效，再在已有报告中使用**刷新项目模板**。

### 12.6 映射检查

模板保存或提交时会检查失效来源。原始记录模板修改字段标识、删除表格或改变表格结构后，旧映射可能失效。看到警告时应逐项重新选择来源，不要只修改显示名称来掩盖问题。

## 13. 生成报告

### 13.1 打开订单

进入**生成报告**，查找并打开订单。页面通常分为录入进度、首页模板和报告编号三部分。报告编号及其默认样品/项目范围由外部接口下发时，以接口数据为准。

### 13.2 先核对原始记录

在录入进度中检查每个“样品 × 测试项目 × 测试方法”的状态。点击可只读查看原始记录和 PDF。

若数据有误：

1. 在工作台或报告编辑器点击**退回原始记录**。
2. 选择具体记录，填写退回原因。
3. 实验室人员修改并重新提交审核。
4. 审核通过后，在报告中刷新项目模板/原始记录，或重新生成对应项目。

只有审核通过并且有有效内容的记录才作为正式报告来源。未填写的试样行或列不会生成空数据。

### 13.3 选择和编辑首页模板

选择已审核生效的首页模板。可以先编辑订单级首页草稿，再点击**应用到报告**，把它应用到该订单的各个报告编号。每份报告生成后仍可独立调整自己的首页；对单份报告的修改不会反向修改模板或其他报告。

首页模板关联主机厂后，项目模板会优先采用相同主机厂候选。若业务格式不同，可在报告条目展开后手工改选。

### 13.4 生成报告

每个报告编号对应一张报告卡片。展开卡片可查看和调整样品、项目及项目模板。

1. 核对报告编号和接口下发范围。
2. 展开样品和测试项目。
3. 勾选需要纳入的项目；可按样品全选，也可逐项选择。
4. 检查每项使用的项目模板，必要时改选。
5. 点击**生成报告**。

系统按当前已有的已审核记录和生效项目模板生成。范围中暂缺记录或模板的项目会跳过，不会阻止其他可用项目生成。生成前页面会标识“待配置项目模板”等原因。

同一项目如果关联三个不同测试方法的原始记录，会按三条项目明细处理；它们的顺序以订单/项目/模板的稳定顺序生成，不应因名称相同被合并成一条。

### 13.5 调整已生成报告的范围

生成后仍可点击**调整样品/项目**：

- 勾选样品可选中其全部可用项目。
- 也可只勾选某些测试方法。
- 首页样品信息表、结论表和项目明细会随范围更新。

确认重算会重置项目明细页中的人工文字和排版修改；首页中大部分结构、图片和样式会保留。调整范围前应先确认是否需要保存当前报告历史版本。

## 14. 报告实例编辑器

报告实例编辑器左侧为接近文字处理软件的连续编辑区，右侧为 PDF。编辑只影响当前报告，不会回写原始记录或模板。

### 14.1 编辑文字

点击普通文字、字段名、字段值或分区标题即可编辑。可执行：

- 输入、删除和选中文字。
- `Enter` 新建段落或空行。
- 在段首按 `Backspace/Delete` 删除相邻空行。
- 设置粗体、斜体、字体、字号和颜色。
- 设置左对齐、居中、右对齐。
- 设置段前、段后和行距。
- 创建项目符号列表。

选中一段文字时使用顶部文字工具栏；选中整个字段时可分别选择**标签**或**内容**进行格式调整。开启**显示编辑标记**可看到辅助边界，这些标记不会进入 PDF。

签发分区中的业务值通常锁定，防止在报告编制阶段改写审批数据，但可调整整个签发区域的位置。

### 14.2 插入内容

将光标放到正文位置，或先选中某个内容块，再点击顶部**插入**：

- **表格**：填写行数和列数，插入到当前位置。
- **图片**：填写图片数量，建立图片框后上传或粘贴。

也可选中整张表格或图片块复制，再粘贴到同一报告的其他位置。内容块可拖动排序、上移、下移或删除。点击**分页**可让当前内容从新页开始。

### 14.3 编辑表格

点击报告表格进入表格编辑。支持：

- 单格或拖动框选多格。
- 修改文字和使用 Excel 网格粘贴。
- 设置字体、字号、粗体、斜体、颜色、对齐和行距。
- 调整整表或选中单元格的格式。
- 增加、删除行列。
- 拖动行高和列宽。
- 合并选区、拆分单元格。
- 修改表头、表格标题和图注。

映射生成的项目自由表格可切换为自由编辑。自由编辑后的文字只属于本报告；刷新项目模板或重算范围时可能恢复为映射数据。

### 14.4 编辑图片

点击图片块后可：

- 上传、替换或删除图片。
- 从右侧原始数据复制原始记录图片。
- 调整顺序、宽高、旋转和压缩。
- 设置每行数量、标题方式、粘连框或独立框。
- 直接编辑表内图片标题；无需填写额外的加粗标签或备注框。

图片超过一页容量时 PDF 自动分页。若希望特定图片另起一页，可对图片块设置分页，或在前方插入分页。

### 14.5 查看和复制原始数据

右侧顶部可切换：

- **报告 PDF**：当前报告渲染结果。
- **原始数据**：结构化字段、表格和图片。
- **原始记录 PDF**：原始记录的完整 PDF。

在原始数据中找到表格或图片后，可复制并粘贴到左侧报告正文，也可用插入功能建立目标位置后替换内容。若原始记录后来新增了模板未映射的行列，页面会提示待核对内容，可从这里手工补入。

### 14.6 刷新项目模板

点击**刷新项目模板**会按当前选中的样品和项目重新拉取最新生效的项目模板及原始记录。首页内容会尽量保留，项目页人工修改会重置。以下情况使用：

- 项目模板新增或修正了映射。
- 图片分区刚补充映射。
- 原始记录退回修改并重新审核。
- 原始记录的试样数量或结果发生变化。

### 14.7 项目分页

每个项目分隔栏旁可选择：

- **项目另起一页**：适合正式报告中项目清晰分隔。
- **接续上一项目**：上一项目剩余空间足够时继续排版，节省页数。

分区和字段还可单独设置分页。修改后以右侧 PDF 逐页核对，尤其要检查大表格、图片和签发区。

### 14.8 签发区域位置

首页签发区提供：

- **首页底部**：固定在首页底部。
- **随正文**：紧接前方正文。
- **当前页底部**：位于当前正文所在页底部；空间不足时移至下一页底部。

项目签字栏可选：

- 跟随正文。
- 居中。
- 底部。

签发值来自报告信息、接口或审核流程时应保持锁定。位置调整只改变排版，不改变签发人、日期、校验码和备注数据。

### 14.9 撤销、重做和保存

编辑器支持撤销、重做和重置。页面显示自动保存状态；完成后点击结束编辑。报告一旦提交审核或进入历史版本即转为只读，右侧 PDF仍可查看和下载。

## 15. 报告审核、历史版本和 PDF

报告完成后提交审核。审核人员应至少检查：

- 报告编号、校验码、签发日期和单位信息是否来自正确接口字段。
- 样品信息、项目范围和测试方法是否完整。
- 原始记录状态是否均为已审核。
- 表格试样数量、单位、公式结果和合并格是否正确。
- 图片标题、顺序、分页和清晰度。
- 结论、判定要求和限值。
- 签发人员、备注和签发区域位置。

已送审或历史报告为只读。系统保存报告版本和当时引用的原始数据快照，便于追溯。外部流程退回报告后，可按意见修改并重新送审。

右侧 PDF 是最终版式依据。点击**下载 PDF**保存文件。若浏览器左侧编辑效果与 PDF 的换行略有不同，应调整列宽、字号或间距并以 PDF 结果为准。

## 16. 用户、角色和权限

### 16.1 我的角色与权限

右上角用户菜单可进入**我的角色与权限**：

- 查看当前角色和实际权限。
- 选择尚未拥有的角色并填写申请理由。
- 查看申请状态。
- 在审核前撤回申请。

### 16.2 用户管理

管理员可在**用户管理**中：

- 给用户分配一个或多个角色。
- 启用或停用账号。
- 创建和编辑自定义角色。
- 为角色勾选权限。
- 审批或驳回角色申请。
- 删除本地用户资料。用户再次通过外部账号登录时会重新以无角色状态建档。

管理员不能停用或删除当前正在使用的自己账号。权限建议按职责最小化分配，模板编辑和模板审核、录入和审核、报告编制和报告审核尽量由不同人员承担。

## 17. 推荐实施方法

### 17.1 上线前准备

1. 维护主机厂库和设备库。
2. 确定字段编码命名规则，公共字段必须跨模板统一。
3. 先建立一份基础原始记录模板并审核。
4. 对结构相近的方法使用派生子模板；只做一次性参考时使用复制。
5. 使用真实 Excel 和边界数据试导入、试算公式。
6. 建立首页和项目模板，逐一检查映射。
7. 用测试订单走完录入、审核、生成、编辑、审核和 PDF 下载。

### 17.2 模板维护原则

- 不要把显示名称当作稳定标识，映射和公共字段依赖字段编码。
- 先修改并审核原始记录模板，再修改报告项目模板。
- 修改试样方向、表格结构或公式后，必须用多试样数据测试。
- 修改图片分区后检查默认图片映射和跨页效果。
- 已生成报告不会因模板改变而自动无条件重写；由编制人员使用刷新功能控制更新时间。

### 17.3 多测试方法推荐结构

对“一个项目、多种方法”的情况：

1. 建立一个原始记录项目组。
2. 创建一份公共结构母模板。
3. 按方法派生子模板。
4. 保持基本信息字段编码、类型和单位一致，并开启公共字段。
5. 每个方法保留独立的结果、图片、结论和审核信息。
6. 每个原始记录模板建立对应的报告项目模板。
7. 生成报告时把各方法作为独立项目明细纳入。

## 18. 常见问题与排查

### 18.1 Excel 导入找不到数据

按顺序检查：

1. 文件是否为 `.xlsx`，是否加密或过大。
2. 模板是否开启允许 Excel 导入。
3. Sheet 名称是否与文件完全一致。
4. 参数表头是否与系统自由表格一致。
5. 是否选对行/列方向和数据区域。
6. 合并表头是否造成参数错位。

仍无法识别时，使用 Excel 复制粘贴，并把文件作为附件保存。

### 18.2 公共字段无法拉取

检查订单、样品和项目是否相同，来源是否为另一份已保存记录；两边字段是否都开启公共字段；字段编码、类型、单位和选项是否一致。

### 18.3 报告只有一个试样

检查原始记录自由表格是否正确设置试样区域和方向，录入中其他试样是否真的有数据；再检查项目模板是否使用**选择试样行/列来源**完成整区绑定。修改项目模板并审核后，在报告中点击**刷新项目模板**。

### 18.4 报告缺少图片

确认原始记录图片已保存并审核；项目模板存在对应图片分区映射；使用的是最新生效项目模板；已有报告点击了刷新项目模板。

### 18.5 报告缺少项目或样品

检查该样品项目是否有已审核原始记录，以及是否存在审核生效且关联正确的项目模板。生成时缺少条件的项目会被跳过；补齐后可调整样品/项目或重新生成。

### 18.6 主机厂显示未关联

在模板列表中点击主机厂列重新选择并保存，然后刷新列表。项目组的主机厂用于组内默认和管理，模板本身仍应显示实际关联。生成报告时检查首页模板和项目模板是否属于同一主机厂。

### 18.7 无法编辑模板或报告

检查是否为待审核、已审核、已发送或历史版本；是否有他人持有编辑权；当前账号是否具备编辑权限。完成审核或撤回后，再点击开始编辑。

### 18.8 页面一直加载

先刷新页面并检查内网是否可访问服务器。若只有部分电脑无法打开，联系管理员检查浏览器版本、代理、防火墙和静态 JS/CSS 请求是否完成。系统前端资源由部署服务器提供，不依赖公网 CDN；网络中途取消或长期 pending 会导致页面无法启动。

## 19. 操作检查清单

### 19.1 原始记录模板发布前

- [ ] 分区、字段名称和字段编码正确。
- [ ] 必填、默认值、选项和单位正确。
- [ ] 公共字段在相关模板中编码、类型、单位一致。
- [ ] 自由表格角色、试样方向、公式和修约规则正确。
- [ ] Excel Sheet 名称和表头已用真实文件验证。
- [ ] 图片布局和分页正确。
- [ ] 结论分区的判定要求选项正确。
- [ ] 右侧 PDF 已用多试样示例核对。
- [ ] 已提交并审核生效。

### 19.2 数据录入提交前

- [ ] 必填字段已填写。
- [ ] 公共字段已拉取并核对。
- [ ] 只保留实际有数据的试样行/列。
- [ ] 公式结果和单位正确。
- [ ] 图片方向、标题、尺寸正确。
- [ ] Excel 和其他附件已上传。
- [ ] 右侧原始记录 PDF 无异常。
- [ ] 已结束编辑并提交审核。

### 19.3 报告模板发布前

- [ ] 首页/项目模板类型正确。
- [ ] 主机厂和项目组归属正确。
- [ ] 项目模板关联正确的原始记录模板。
- [ ] 普通字段、试样区、图片和设备映射完整。
- [ ] 校验码、签发备注等使用正确接口来源。
- [ ] 空试样不显示，多试样可正确扩展。
- [ ] 表格合并、图片分页和项目分页正确。
- [ ] 已审核生效。

### 19.4 报告送审前

- [ ] 报告编号和首页模板正确。
- [ ] 样品、项目和测试方法范围完整。
- [ ] 原始记录均已审核。
- [ ] 首页样品信息表和检测结论表正确。
- [ ] 表格、图片、设备和结论均已拉取。
- [ ] 项目顺序、分页和签发区位置正确。
- [ ] 校验码、日期、签发人员和备注正确。
- [ ] 逐页检查右侧 PDF 并下载留样。
