# 自由表格公式设计

## 目标

原始记录模板不再新增“数据表格”，统一使用自由表格。存量 `data_matrix` 模板继续读取、录入和生成报告，不做破坏性迁移。

自由表格的公式交互参考 Excel：选中格后可看到“名称框 + fx 公式栏”，公式格内同时显示公式类型和公式摘要。公式编辑仍按独立配置项保存，不把整块表格或公式打包成一个文本字段。

## 引用规则

- 同一张表：界面使用 `A1`、`B3` 等地址。
- 不同表：界面使用 `'表格名称'!A1` 描述来源，自定义表达式使用 `T_字段编码_A1` 这样的安全别名。
- 持久化不使用可修改的表名，而使用 `@free-grid:<fieldCode>:<cellKey>`。因此修改表名不会断开公式，行列内部也仍由稳定 id 关联。
- 历史同表公式仍使用 `rowId::colId`，无需迁移。

跨表公式可以继续引用另一个公式格。录入端与报告端均递归解析依赖，不依赖字段在模板里的先后顺序；保存时会遍历全模板依赖图并拒绝直接或间接循环引用。

## 编辑与试算

1. 选中目标格，点击公式栏右侧“设置公式”。
2. 选择平均、求和、最大、最小或自定义公式。
3. 当前表可直接点格选择来源；跨表在“引用表格”中切换表格，再点来源单元格。
4. 自定义公式支持 `+ - * / ^ % ( )`，可输入或粘贴带 `=` 的公式；系统保存时会规范化开头的等号。
5. 每个来源都可填试算值。预设公式和自定义公式都会即时给出“试算通过 + 结果”或明确的未通过状态。

公式的显示精度继续由目标单元格的数字格式决定，试算、数据录入和报告生成使用同一公式执行引擎。

公式编辑器会展开“计算依赖链”：直接来源如果也是公式格，会继续显示其公式以及更底层的来源格。试算只要求填写最底层的原始输入格，过程公式由系统自动重算。

### 计算精度

公式计算与数字显示严格分离。公式链内部始终传递 JavaScript 数值的完整精度，`cell_number_fmt` 只在最终单元格显示和 PDF 排版时应用。例如 B1 的真实结果为 `1 / 3`、显示为 `0.33`，C1 引用 B1 时使用的仍是完整的 `0.333333…`，而不是 `0.33`。

数值修约是独立的显式规则：单元格 `cell_rounding` 优先于整表 `default_rounding`，先修约实际值，再应用数字显示格式。可选四舍五入、四舍六入五成双、截尾、向上/向下修约、最接近偶数和最接近 5 的倍数。未配置修约时仍保持完整精度；配置后，修约结果会作为该格实际数值供下游公式引用。因此“保留 2 位小数”只改变外观，而“修约至 2 位”会明确改变计算值，两者可以同时选择。

历史公式中保存的 `Formula.decimals` 在自由表格公式链里也会被忽略，避免旧模板继续产生逐级舍入误差；只有用户明确使用 `ROUND`、`ROUNDUP`、`ROUNDDOWN` 或 `round_format` 时，取整才属于公式本身并参与后续计算。人工修正值属于用户明确覆盖，后续公式会使用该覆盖值。

### 数学与统计函数

自定义公式编辑区使用“fx 公式库”，不在画布中平铺函数按钮。公式库按统计、幂与根、指数与对数、取整、三角函数、比例与常量分类，可按中文名称或函数名搜索。每个条目均展示参数格式、用途和基于当前来源格生成的示例；来源数量不足时仍可阅读说明，但不能插入无效公式。

公式库采用“插入/组合”而不是覆盖：公式为空时直接插入；已有公式时，用户先选择加、减、乘、除，再把新公式与旧公式分别加括号后组合，例如 `(STDEV.S(A1,A2,A3)) + (AVERAGE(A1,A2,A3))`。如果用户在公式文本框中选中一段内容，则新公式只替换该选区，便于构造嵌套函数。

- 幂与根：`A1^2`、`POWER(A1, 3)`、`SQRT(A1)`、`ROOT(A1, 3)`。
- 统计：`STDEV.S(...)`（样本标准差）、`STDEV.P(...)`（总体标准差）、`VAR.S(...)`、`VAR.P(...)`、`MEDIAN(...)`、`AVERAGE(...)`。
- 聚合：`SUM(...)`、`MIN(...)`、`MAX(...)`、`COUNT(...)`、`PRODUCT(...)`。
- 数值处理：`ABS(...)`、`ROUND(...)`、`ROUNDUP(...)`、`ROUNDDOWN(...)`、`CEILING(...)`、`FLOOR(...)`、`MOD(...)`。
- 指数、对数和三角：`EXP(...)`、`LN(...)`、`LOG(...)`、`LOG10(...)`、`SIN(...)`、`COS(...)`、`TAN(...)`。

例如，先选择 A1、A2、A3，再使用 `STDEV.S(A1, A2, A3)` 计算样本标准差；需要输出百分数数值时，变异系数可写成 `STDEV.S(A1, A2, A3) / AVERAGE(A1, A2, A3) * 100`。当前不解析 `A1:A10` 范围语法，连续区域通过框选/逐格选择后由引用列表明确保存，避免表格结构调整后范围含义悄然变化。

## 兼容边界

- “数据表格”字段类型和计算代码保留，仅从新增字段菜单与“试验结果”预设中隐藏。
- 新“试验结果”预设创建自由表格。
- 样品带内的同表公式沿用原有逐样品/汇总展开规则；跨表引用在有相同样品序号时取对应样品值，否则取普通格或模板固定值。
- PDF/报告解析支持跨表公式链与手动覆盖值。
